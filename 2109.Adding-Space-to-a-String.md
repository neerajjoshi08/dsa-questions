### Link:
https://leetcode.com/problems/adding-spaces-to-a-string

### Description:
- We are given a string s: "Helloleetcode", and space array like: [1, 2, 3, 4] (strictly increasing)
- We need to append the spaces in the string s at the positions described in space array
- space array elements would be within the range of length of string array


### Approach:
- We can iterate over the string and will check if the string index matches with the index of space array like `space[space_index] == string_index`.
- If it does will add the space in the resultant string, and then add the current element present at that index.
- Will return the resultant string.

### Notes:
- The approach can be optimized by the resultant string taken as per the programming language. We need to create a string ensuring the default capacity would be length of s + length of space array.
- This way at the startup the string size can be allocated rather than dynamically modifying.

C++:
```cpp
  string result;
  result.reserve(s.length() + space.size());
```

Java:
```java
  StringBuilder sb;
  sb.ensureCapacity(s.length() + space.size())
```
